Por organismo

Las siete situaciones

Semana por semana

Cada semana queda guardada con sus tres listas. Se cuenta con lo confirmado hasta hoy en «¿Es la misma persona?»: una confirmación corrige también las semanas anteriores. «Ver» muestra el cotejo de esa semana, en «Buscar». Lo publicado para la consulta queda como se publicó.

Las tres listas

Cada una se carga cuando llega la nueva, pegándola desde Excel o abriendo el archivo tal como viene. La que no se actualiza sigue con la de antes.

¿Es la misma persona?

El índice del protocolo y el de la web no traen DNI, así que se cruzan por el nombre. Cuando no alcanza para estar seguro, se pregunta. Lo que se contesta queda recordado para las semanas siguientes.

Revisar las inconsistencias

DDJJ que pueden ser de otro cargo, cargos u organismos que no coinciden o no se pueden leer, y quien presentó por un organismo de la nómina sin estar en ella. Hasta revisarlas, cuentan como presentadas.

Publicar para la consulta

La página Consulta DDJJ muestra lo que se publica desde acá, para buscar a alguien o bajar el Excel de un organismo sin tocar el cotejo. Se publica una vez por semana, después de cargar las listas, con una clave: los datos quedan cifrados y la consulta la pide para mostrarlos. Queda en el archivo consulta-ddjj-datos.html, en la carpeta del cotejo del disco R.

Dónde queda guardado

Lo cargado queda en esta computadora. Para pasarlo a otra, o para tener un respaldo, se guarda una copia en un archivo y se abre en la otra.
